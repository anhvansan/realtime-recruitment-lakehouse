## 2. Bài học & Sửa lỗi tương thích khi chạy thật

1. **Python 3.10.12 trong container `apache/spark:3.5.3`:**
   - `from datetime import UTC` chỉ hỗ trợ từ Python 3.11 ➔ sửa toàn bộ `src/` sang `datetime.timezone.utc` và chốt `target-version = "py310"` trong [pyproject.toml](file:///d:/realtime-recruitment-lakehouse/pyproject.toml#L26).
2. **`try_to_date` chỉ có từ Spark 4.0:**
   - Spark 3.5.3 báo `[UNRESOLVED_ROUTINE]` với `try_to_date` ➔ thay bằng `try_cast(substring(..., 1, 10) as date)` trong [validation.py](file:///d:/realtime-recruitment-lakehouse/src/streaming/validation.py#L98-L326) để các ngày sai lịch như `2026-02-30` trả về `NULL` an toàn và bị bắt thành `bad_timestamp`.
3. **Bẫy `from_json` ép kiểu ngầm:**
   - Spark `from_json` tự ép số JSON thô (`"spend": 12.5`) sang `StringType` ➔ dùng regex kiểm tra token JSON gốc trên `payload_raw` giữ parity 100% với `validate_event()` (ADR-007).
