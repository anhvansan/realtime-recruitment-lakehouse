2. **Pin `duckdb==1.5.6` trong container Spark (Ubuntu 22.04 / Python 3.10.12):**
   - Image chính thức `apache/spark:3.5.3-scala2.12-java17-python3-ubuntu` dùng Python 3.10.12 chưa có wheel `duckdb==2.0.0` trên PyPI; `duckdb==1.5.6` (Delta Kernel) vượt qua cả Deletion Vectors (`minReaderVersion=3, minWriterVersion=7`). Host Windows giữ `duckdb==2.0.0`.

## 4. Điều học được / điều làm tôi bất ngờ

- `df.write.format("delta").option("delta.enableDeletionVectors", "true")` không tự bật table feature nếu không set qua `TBLPROPERTIES` (`ALTER TABLE delta.\`...\` SET TBLPROPERTIES ('delta.enableDeletionVectors' = 'true')`) hoặc Spark default conf.
- DuckDB `1.5.6` với extension `delta` (Delta Kernel) hỗ trợ đọc bản địa **Deletion Vectors** (Protocol v3/v7) tạo ra bởi Spark `3.5.3` + Delta `3.2.1` trên MinIO mà không cần tắt tính năng bảng.
- Phân tách lớp cache Docker cho `aws-java-sdk-bundle` (~270MB) và giữ nguyên tầng `pip3` giúp rebuild sau khi sửa code/script cực nhanh (4.3s).
